# Настройки 0.2.1

Вместо длинной общей формы доступны шесть вкладок: перевод, экран, словарь, клавиши, игры и приложение. Подключения показывают только относящиеся к выбранному сервису поля; редкие параметры раскрываются отдельно. Помощник объяснений находится в словарной вкладке.

Кнопки сохранения и отмены закреплены внизу. Отмена возвращает сохранённые значения, а переходы по приложению сохраняют черновик до завершения процесса. Черновики ключей не теряются при переключении провайдеров. Проверка подключения использует введённые адрес и ключ, позволяет отменить запрос и не записывает настройки. Ошибки сохранения открывают соответствующую вкладку и дополнительный раздел.

Размер и плотность подложки регулируются ползунками с предпросмотром. Глобальные сочетания приложения временно отключаются при записи новой горячей клавиши. Профиль игры сохраняется вместе с текущими изменениями настроек. Предупреждения о занятых сочетаниях не перекрываются сообщением об успешном сохранении.

Проверено: 67 доменных/инфраструктурных тестов, 34 проверки новой формы с настоящими WPF-контролами, локальными файлами настроек и явно обозначенными HTTP-заглушками. Проверены шесть вкладок при 960×650 и светлая тема. Снимки и результаты: `artifacts/settings-ux`. Живые облачные ключи в этих проверках не используются.

При упаковке NuGet сообщил NU1900: внешний каталог данных об уязвимостях был временно недоступен. Сборка выполнена из уже восстановленных зависимостей; это не подтверждение свежей проверки каталога уязвимостей.
