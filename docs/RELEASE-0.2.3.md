# Быстрый первый перевод слова 0.2.3

Alt+W открывает словарь сразу после OCR. До открытия окна больше не переводится целая реплика, а перевод слова не ждёт JSON-карточку помощника. Сначала используется сохранённая карточка или кэш слова без привязки к реплике; при отсутствии результата выбранный переводчик получает только слово. Контекст, объяснение и дополнительные статьи загружаются после первого результата. Другие провайдеры автоматически не подключаются.

Слово расположено вверху окна и доступно для сохранения, пока загружаются дополнения. Позже показывается значение в реплике, а первый вариант остаётся виден. Ошибки уточнения сохраняют первый результат. Изменение слова и закрытие окна отменяют фоновые запросы; устаревший ответ не заменяет новое слово. Сохранение фиксирует видимые в момент нажатия данные; фоновое уточнение не меняет уже сохранённую карточку. История получает перевод реплики после завершения, без пустых успешных записей.

Выбранная при запуске модель PP-OCRv6 подготавливается в фоне, без снимков экрана. Подготовка и распознавание используют одну блокировку; завершение приложения дожидается подготовки перед освобождением OCR. Для короткого захвата Alt+W сокращены задержки ожидания перерисовки. В диагностике отдельно отмечается время до первого перевода без записи текста.

Проверены 67 unit-тестов, 23 проверки поэтапного словаря и 31 общая Windows-проверка. Реальные LibreTranslate и Ollama проверены отдельно, также с настоящим GDI-захватом и PP-OCRv6 Medium. После подготовки OCR в тестовой реплике первый результат появился примерно за 0,99 с от начала захвата: ~0,82 с захват/OCR и ~0,17 с перевод слова. Контекст и уточнение в этот момент ещё загружались. Без предварительной подготовки первый результат занял ~2,0 с. Это замеры конкретной реплики и машины; время в играх зависит от сцены и прогрева моделей. Автоматическое нажатие горячей клавиши через управление тестовым окном не проверено: ожидание разрешения на это окно истекло. Проверен вызываемый горячей клавишей путь захвата напрямую.

Артефакты: `artifacts/lookup-progressive`, `artifacts/lookup-live`, `artifacts/lookup-real`, `artifacts/lookup-warm`, `artifacts/lookup-regression`. Новых внешних зависимостей нет. NuGet сообщил NU1900 о недоступности каталога уязвимостей; сборка из восстановленных зависимостей не подтверждает свежую проверку этого каталога.
