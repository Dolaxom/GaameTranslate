## Различия и незакрытые сценарии

- Полноценная навигация всей программой геймпадом, HID-контроллеры и пользовательская раскладка контроллера ещё не реализованы. Текущие сочетания не равны полной поддержке контроллера.
- MDX/MDD, SLOB, специализированные JMdict/JMnedict/KANJIDIC и WordNet-архивы не импортируются напрямую. Конвертированные Yomitan/StarDict-версии могут использоваться в рамках поддерживаемого текстового формата. Встроенного лицензированного универсального словаря нет.
- Нет автоматических альтернатив перевода, отдельного морфологического движка для каждого языка, словарного аудио из архивов и синхронизации всего состояния между компьютерами.
- Нет приостановки процесса игры, эксклюзивного полноэкранного внедрения, отдельного Windows Graphics Capture backend или гарантии обхода ограничений защищённого контента.
- Пространственная замена использует цветовую подложку и подбор шрифта. Восстановления картинки под текстом/inpainting нет. Длинный перевод может потребовать уменьшения шрифта; полный текст есть в подсказке и окне приложения.
- Работа на одном проверенном дисплее не подтверждает всю матрицу mixed-DPI, нескольких мониторов и игр.

«Лучше Lookupper» требует воспроизводимого слепого сравнения: одинаковые кадры без уже наложенного перевода, эталонная расшифровка, оценка ошибок OCR, смысла/терминов/тона перевода, задержки и удобства выбора слов. Два присланных кадра полезны для регрессий, но не доказывают общего превосходства.
