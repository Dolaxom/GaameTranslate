# Изменения 0.2

Переводческий блок расширен официальными API Yandex Translate, YandexGPT, GigaChat, локальным Ollama и OpenAI-compatible серверами. У каждого сервиса отдельные учётные данные. Перевод и словарное объяснение могут использовать разные модели. Таймаут настраивается; невалидные ответы не записываются как успешные переводы.

OCR теперь может использовать встроенные PP-OCRv6 Small/Medium с координатами символов и слов. Windows OCR остаётся для других языков. Добавлена регрессия по реплике JOYCE MESSIER: выделенное Better разделяло строку на два OCR-блока. Теперь части строки соединяются перед объединением абзацев, и продолжение про forestay/backstay не теряется.

Alt+Q запускает перевод экрана с подбором подложки и размера текста. Alt+W открывает слово под курсором. В слое можно показывать оригинал и выбирать слова по их реальным OCR-областям. Доступны визуальная фиксация изображения, явно запускаемый автоперевод области, игровые профили по .exe и ограниченные XInput-сочетания.

Словарное окно показывает контекст, определения, произношение, примеры, синонимы, озвучку и отдельно запрашиваемое AI-объяснение. Добавлен локальный импорт Yomitan/DSL/StarDict/Kaikki/CC-CEDICT. Расширенные поля и опциональные PNG/WAV сохраняются в карточки. Экспорт APKG включает медиа. AnkiConnect обновляет существующие заметки и помечает отсутствующие вместо удаления.

## Проверено

- 67 доменных/инфраструктурных тестов, включая реальные SQLite/ZIP и контрактные HTTP-обработчики без пользовательских API-ключей.
- 31 нативная проверка Windows: страницы WPF, GDI → Windows OCR → явно помеченный тестовый HTTP-ответ, четыре слоя, click-through, горячие клавиши, SQLite, DPAPI, реальная WAV-озвучка, профили активного процесса и защита от привязки чужого снимка к истории.
- APKG импортирован движком Anki 26.9.3: одна заметка, две карточки; повторный импорт не создал дубликат.
- PP-OCRv6 Small/Medium запущены на пользовательском английском кадре, результаты и разметка сохранены в artifacts/quality*. На русском кадре честно используется Windows OCR.
- Локальный TranslateGemma получил реальную полную реплику. Он ошибся в морских терминах: улучшение OCR не означает автоматического улучшения смысла перевода. Сравнение с контекстной моделью проводится отдельно.
- Qwen3 4B Instruct также успешно прошёл настоящий API-прогон: JSON-перевод и контекстная статья получены, но морские термины остались неверными. На этом кадре OCR занял около 0.7–0.9 с, перевод — около 2.4–3.6 с, TranslateGemma — около 3.1–4.6 с при готовых моделях. Первый холодный запуск может быть значительно дольше. Это проверка работоспособности, а не подтверждение превосходства в переводе.
- Обычный тег qwen3:4b оказался Thinking-псевдонимом; для установочного скрипта и помощника закреплён qwen3:4b-instruct-2507-q4_K_M. Выбор модели имеет значение для корректного структурированного ответа.

Yandex/GigaChat/DeepL/Azure проверены контрактными тестами; живые аккаунты и квоты требуют пользовательских ключей. Физический геймпад и другие конфигурации мониторов не проверены. Полное сопоставление и оставшиеся различия: [LOOKUPPER-COMPARISON](LOOKUPPER-COMPARISON.md).
