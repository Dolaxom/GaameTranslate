# Статус и оставшаяся работа

Версия 0.2 реализует экранный перевод, выбор слова под курсором, PP-OCRv6,
контекстные модели, российские API, локальные словари, озвучку, карточки,
APKG/AnkiConnect, автоперевод области, базовые игровые профили и XInput-сочетания.
Подробный статус функций: [LOOKUPPER-COMPARISON](LOOKUPPER-COMPARISON.md).

До заявления о превосходстве над Lookupper нужен одинаковый игровой корпус
без наложенного перевода, ручная расшифровка, слепая оценка смысла/терминов/тона,
замеры тёплого и холодного запуска и проверка удобства словарного выбора.

Следующие приоритеты:

1. Проверка реальными аккаунтами Yandex Translate / YandexGPT / GigaChat:
   доступность, IAM, квоты, ошибки и разные языки. Ключи предоставляет владелец.
2. Windows Graphics Capture, несколько мониторов, mixed-DPI, смена дисплеев,
   реальные borderless-игры и длительный сеанс с контролем памяти/дескрипторов.
3. Более точный анализ вертикального японского, фуриганы, повернутого текста,
   автоматическое определение смешанных письменностей и морфология.
4. Дополнительные словарные контейнеры MDX/MDD, SLOB и специализированные XML;
   словарное аудио и связанные статьи.
5. Полная навигация геймпадом, пользовательские раскладки и HID.
6. Доступность: Narrator, высокая контрастность, большой текст, клавиатурная
   навигация по пространственным словам.
7. Подписанный установщик/обновления, безопасный бэкап и миграции данных,
   статистика обучения и запоминание геометрии окон.

Сборка остаётся портативной и неподписанной. Снимки и локальный словарь
не зашифрованы. Эти ограничения описаны в README; неработающие сценарии
не маскируются фиктивными результатами.
